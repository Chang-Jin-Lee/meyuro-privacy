# meyuro privacy policies

Public privacy documents for meyuro games. This repository contains static public documents only.

- DECKMATE policy: https://chang-jin-lee.github.io/meyuro-privacy/deckmate/
- 지원 및 개인정보 문의 / Support and privacy: alicepyongpyong@gmail.com
- 공개 문의 / Public inquiries: https://github.com/Chang-Jin-Lee/meyuro-privacy/issues
- Developer: meyuro
- Package: `com.meyuro.deckmate`

GitHub Pages publishes the root of the `main` branch. `.nojekyll` keeps deployment static. No scripts, analytics, external fonts or secrets are needed.

Edit `deckmate/index.html` in Korean and English together. Keep the policy aligned with the actual released build and update the revision date. Before releasing a new build, verify its packaged permissions, SDKs, network activity and store-provided enhancements. The policy does not replace the final Google Play Data safety declaration.

The inquiry board is public. Do not post credentials, private contact details, identity documents or private logs.
